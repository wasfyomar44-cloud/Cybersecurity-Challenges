# Cybersecurity Challenges in Web Development

This repository contains a short technical report written in LaTeX for the essay topic **Cybersecurity Challenges in Web Development**.

## How to compile

Using a local LaTeX installation:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The final compiled file is `report.pdf`.

## Repository contents

- `main.tex` - LaTeX source file
- `references.bib` - BibTeX bibliography file
- `report.pdf` - compiled PDF report
- `git-log.txt` - exported Git commit history
